# WIRD — إجراءات المالك المؤجلة

تُجمع هنا الخطوات التي تتطلب جهازًا حقيقيًا أو صلاحية مالك. لا توقف الأعمال الآلية المستقلة بسببها.

## حاليًا
1. **Google AI Studio:** تأكد من مزامنة المشروع المتصل بمستودع `xm8eslam-stack/WIRD-APP` وفرع `main` بعد دمج تغييرات الوثائق؛ لا تفترض أن commit GitHub يثبت مزامنة AI Studio.
2. **أجهزة حقيقية:** بعد نشر Production على SHA حديث، اختبر A↔B للمزامنة. يوجد نجاح محدود أبلغ عنه المالك، لكنه لا يغطي crash/offline الطويل.
3. **Offline audio:** بعد اكتمال الميزة، اختر سورة قصيرة واختبر التشغيل بعد قطع الإنترنت. لا إجراء الآن.
4. **سعة الجهاز:** إذا رفض المتصفح persistent storage أو كانت المساحة منخفضة، أفرغ مساحة قبل تنزيل صوت كبير.

## لا تنفذ دون موافقة منفصلة
- تغيير Vercel/Firebase secrets أو environment variables.
- تغيير sync flags أو إعدادات الإنتاج.
- نشر يدوي أو ترقية Production خارج GitHub→Vercel.
- نشر Firestore Rules أو تعديل بيانات مستخدم حقيقية.
