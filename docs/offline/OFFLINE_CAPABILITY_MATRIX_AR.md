**تاريخ الجرد:** 12 نوفمبر 2026
**مرجع المصدر:** main عند 8e98aa350c999b2252cc8e3b5d2a8c6d0264b86b
**الحالة:** جرد أولي من تسجيل المسارات والملفات المعروفة؛ ليس اعتمادًا نهائيًا لكل مسار.

## حالات الإتاحة
- **مدمج:** يأتي مع التطبيق ولا يحتاج اتصالًا أو تنزيلًا منفصلًا.
- **حزمة Offline:** يجب تنزيل ملفات المسار صراحةً قبل فصل الإنترنت.
- **مخزن سابقًا:** متاح فقط إذا سبق تحميله والتحقق منه وما زال داخل سياسة الصلاحية.
- **انتهازي:** قد يبقى في cache محدود وقد يحذفه المتصفح.
- **شبكي:** يتطلب اتصالًا أو اعتمادًا/خدمة خارجية.
- **غير مدقق:** لم تُثبت جميع تبعيات المسار بعد.

## موارد مشتركة
| المورد | الموجود | المخاطر/العمل المتبقي |
|---|---|---|
| App shell | Service Worker + manifest + HTML fallback + ملفات JS/CSS الابتدائية | اختبار cold start/restart في وضع الطيران لكل متصفح مستهدف |
| Lazy chunks | Vite build manifest يجمع static dependency graph وallAssets | إثبات أن كل import ديناميكي وجميع ملفات route موجودة في الحزمة الناتجة |
| ملفات public | أضيف جرد recursive للملفات العامة المدعومة ودمجها في allAssets للحزمة الصريحة؛ sw.js مستثنى عمدًا | يجب التحقق من build output الفعلي ومن حجم الملفات العامة ومدى حاجة كل مسار لها |
| الخطوط | خط قرآني رسمي له محاولة pre-cache؛ Google Fonts تُخزن عند الطلب | قد لا تتوفر خطوط Google في أول فتح Offline؛ اختبار fallback وخيارات تضمين محلي مرخص |
| نص القرآن | بيانات محلية مجزأة ومتحقق منها | اختبار كل chunks وsearch indexes بعد package/restart |
| تفسير | cache بعد العرض وفق الخدمة الحالية | غير المحفوظ يحتاج الإنترنت؛ تحقق من freshness/expiry وسعة cache |
| أحاديث مرتبطة | cache بعد التحقق الصريح من الإسناد/المتن والدرجة | لا تعرض غير المخزن ولا تولد بديلًا |
| الصوت | 20 آية كحد للتخزين الانتهازي، cache بحد 40 عنصرًا؛ مصادر مقيدة | ليس مكتبة كاملة؛ تنزيلات pinned لم تنفذ بعد؛ EveryAyah stream-only |
| صفحات المصحف المصورة | cache منفصل محدود حتى 24 صفحة | ليس مصحفًا كاملًا Offline؛ تنزيل اختياري يحتاج حقوق/حجم/واجهة |
| Auth/Firebase/Firestore | خدمات سحابية | لا تعمل Offline؛ يجب أن تبقى القراءة/التقدم المحلي ممكنة دونها |
| APIs | /api مستثناة من cache العام | تبقى شبكية؛ لا تخزين لردود خاصة أو مفاتيح |

## فجوات مثبتة تحتاج تنفيذًا أو اختبارًا
1. Router الحالي يسجل المسارات عبر hash؛ يجب أن تغطي اختبارات الروابط العميقة كل المسارات وليس seerah فقط عند دمج PR الخاص بها.
2. أُضيفت ملفات public المدعومة إلى allAssets؛ ما زال يلزم التحقق من build output والـ fonts الخارجية وسياسة الأحجام.
3. تسجيل Service Worker يحدث بعد load في الإنتاج؛ يجب اختبار أول زيارة ثم reload ثم انقطاع الشبكة، وعدم افتراض أن الصفحة الأولى أصبحت controlled فورًا.
4. فحص حزمة Offline الحالية لا يثبت صلاحية كل ميزة؛ status الحالي يصف ملفات البناء التي دخلت manifest فقط.
5. لا يوجد في هذا الجرد إثبات حقيقي لتشغيل الهاتف في وضع الطيران بعد إغلاق التطبيق وإعادة تشغيله.
6. لا يوجد إثبات بعد أن كل العمليات المحلية تنجح أثناء انقطاع الإنترنت مع AuthGate أو أي تهيئة تعتمد على Firebase.
7. لا توجد بعد مكتبة تنزيل صوت كاملة؛ الخطة التفصيلية في OFFLINE_AUDIO_DOWNLOAD_PLAN.md.

## تحديث 12 نوفمبر 2026

- أُضيف timeout مقداره 6 ثوانٍ لطلب التنقل قبل الرجوع إلى index.html المحفوظ، مع assertion في اختبار PWA.
- حزمة Offline الصريحة تضم الآن الملفات العامة المدعومة من public بجانب ملفات build، ويُستثنى sw.js عمدًا.
- ما زال اختبار airplane-mode بعد restart غير منفذ.

## معايير تحديث هذه المصفوفة
- لا تحول التصنيف إلى مدمج/جاهز إلا بعد فحص الكود والاختبار المقابل.
- سجّل اسم المتصفح/الجهاز وSHA عند الاختبار الواقعي.
- إذا كان المسار يعمل فقط بعد زيارة سابقة، صنفه مخزنًا سابقًا لا مدمجًا.
- إذا كان المحتوى قد يُحذف بفعل ضغط التخزين، صنفه انتهازيًا لا تنزيلًا مثبتًا.
- لا تخلط توفر واجهة الصفحة مع توفر البيانات أو الأفعال التي تقدمها.
